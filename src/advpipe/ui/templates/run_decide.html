You'll finish this by hand. Taking over ends the run:

{%- elif choice == "finish" %}

Finish run {{ run_id }} as it is?

A usage limit stopped this run part-way through. Finishing ends it here:

  • nothing is committed: the work so far stays in its working copy {%- if info.worktree %} {{ info.worktree }}{% endif %}, uncommitted, for you to look at (git -C <working copy> status) and do with as you please;
  • the branch{% if info.branch %} {{ info.branch }}{% endif %} keeps the commits of the steps that finished;
  • the run can't be resumed or decided again. Cleaning it up later refuses to delete the uncommitted work unless you say so.
